### [X-Filer](https://x-filer.com/?utm_source=github&utm_medium=profile) · author

**A file manager for Windows and macOS that shows what your AI agent did in your project.** X-Filer tells you what Claude Code changed since your last visit in plain words, without git or an IDE: compare before and after, read and fix notes, put a file back as it was. And it's a full file manager in the spirit of Arc: Spaces, split view, and Google Drive / Yandex Disk right in the sidebar.

.NET 10 · Avalonia UI · Native AOT · `v0.3.0-beta`
